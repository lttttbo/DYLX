下面继续 emulate_arm.c 中 arm_instgrp_coproc 的通用协处理器分支，本批覆盖：
cpro != 0xA 且 cpro != 0xB
op1 = 0x00 ～ 0x1F
正式编号接续上一批：
arm_instgrp_coproc.065.IN ～ arm_instgrp_coproc.066.IN
arm_instgrp_coproc.067.R  ～ arm_instgrp_coproc.096.R
本批不设置 CPRO 字段，因此：
cpro = 0
会直接进入：
default: /* Generic coprocessor instructions */
除 op1=0x03 外，不设置 Rn 字段，使其保持：
Rn = 0
从而选择 LDC immediate 路径。op1=0x03 单独设置 Rn=15，用于覆盖 LDC literal 路径。
不需要增加 User Global、辅助宏或调用打点。
公共 Stub 配置
vmm_vcpu_irq_assert：空实现
每条有效分派用例只将对应目标函数设置为：
返回 VMM_OK
其他叶子函数保持默认返回 VMM_EFAIL。
 
⸻
