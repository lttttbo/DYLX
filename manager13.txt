下面仅重新整理 vmm_manager_guest_create() 的既有用例，不改变用例编号、测试场景、输入、预期结果或覆盖目标。
统一约定如下：
	•	G0-UC、G1-UC、B0-UC 仅指 Begin User Code 基线。
	•	S0-STUB 仅指 成功路径 Stub 配置参考。
	•	每条用例只配置当前执行路径实际会调用的 Stub，不要求把整个 S0-STUB 原样复制。
	•	非本 .c 文件中的函数会被 VectorCAST 自动 Stub；需要成功返回时必须显式设置，不能依赖默认值 0。
	•	strcmp、strlcpy、strlcat、memset、memcpy 在本函数测试中使用 Actual。
	•	基础配置 30 条；定义 CONFIG_TEE 时追加 3 条。
 
⸻

3. 修改现有 
vcast_manager_prepare_guest_env
void vcast_manager_prepare_guest_env(u32 guest_count)
{
    u32 g;

    memset(vcast_guest_array,
           0,
           sizeof(vcast_guest_array));

    memset(vcast_guest_avail_array,
           0,
           sizeof(vcast_guest_avail_array));

    memset(vcast_guest_work_store,
           0,
           sizeof(vcast_guest_work_store));

    INIT_LIST_HEAD(&mngr.guest_list);

    for (g = 0U;
         g < (u32)CONFIG_MAX_GUEST_COUNT;
         ++g) {
        INIT_LIST_HEAD(&vcast_guest_array[g].head);

        vcast_guest_array[g].id = g;
        vcast_guest_avail_array[g] = TRUE;

        /*
         * 前 guest_count 个 Guest 视为已占用，
         * 并加入 mngr.guest_list。
         */
        if (g < guest_count) {
            vcast_guest_avail_array[g] = FALSE;

            list_add_tail(
                &vcast_guest_array[g].head,
                &mngr.guest_list);
        }
    }

    mngr.guest_array = vcast_guest_array;
    mngr.guest_avail_array =
        vcast_guest_avail_array;

    mngr.guest_work_array =
        &vcast_guest_work_store[1];

    mngr.guest_count = guest_count;

    vcast_expected_guest = NULL;
}
原辅助函数用例使用 guest_count=2U 时，预期同步调整为：
vcast_guest_avail_array[0] = FALSE
vcast_guest_avail_array[1] = FALSE
vcast_guest_avail_array[2] = TRUE

/*
 * 改写目的：
 * vmm_cpumask_set_cpu 是 static inline 函数，不能直接 Stub。
 *
 * 在 vmm_cpumask.h 完成 inline 定义后，使用同名函数式宏
 * 遮蔽 UUT 中的调用，避免进入 set_bit 及底层原子/汇编实现。
 *
 * affinity 是否为空、是否属于 domain，分别通过
 * __bitmap_weight、__bitmap_subset、__bitmap_equal 控制。
 */
#define vmm_cpumask_set_cpu(cpu, dstp)       \
    do {                                     \
        (void)(cpu);                         \
        (void)(dstp);                        \
    } while (0)

/*
 * 改写目的：
 * vmm_cpu_online 是宏，由测试变量控制 CPU 是否在线。
 */
#ifdef vmm_cpu_online
#undef vmm_cpu_online
#endif

#define vmm_cpu_online(cpu)                  \
    ((void)(cpu),                            \
     (bool)(vcast_cpu_online_ret != 0U))

/*
 * 改写目的：
 * 隔离真实设备树子节点链表。
 */
#ifdef vmm_devtree_for_each_child
#undef vmm_devtree_for_each_child
#endif

#define vmm_devtree_for_each_child(child, parent) \
    for ((void)(parent),                           \
         (child) = vcast_dt_child;                 \
         (child) != NULL;                          \
         (child) = NULL)

九、不可达及编译期路径
1. 最小优先级判断 true 不可达
if (vcpu->priority < VMM_VCPU_MIN_PRIORITY)
当前：
#define VMM_VCPU_MIN_PRIORITY 0
且 vcpu->priority 为 u8，不存在小于 0 的输入。
2. Guest 分配失败中的 
!guest
if (!guest ||
    gnum == CONFIG_MAX_GUEST_COUNT)
list_for_each_entry 循环结束后，guest 可能是基于链表头计算的哨兵容器地址，而不是 NULL。因此资源耗尽通常通过：
!guest = false
gnum == CONFIG_MAX_GUEST_COUNT = true
进入失败路径。
3. 
CONFIG_CPU_BE
#ifdef CONFIG_CPU_BE
    guest->is_big_endian = TRUE;
#else
    guest->is_big_endian = FALSE;
#endif
这是编译期路径，一次环境只能覆盖其中一个版本。
