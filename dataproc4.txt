下面继续补充 op2=0xF 的 20 个可达 case 标签，正式编号为：
arm_instgrp_dataproc.073.R ～ arm_instgrp_dataproc.092.R
最后增加：
arm_instgrp_dataproc.093.IN
用于覆盖同步原语判断中：
(op1 & 0x10) != 0    /* true */
op2 == 0x9           /* false */
本批不新增 User Code，也不增加调用打点。
统一使用基础指令：
0xE00120F4U
其固定字段为：
op   = 0
op1  = 0
op2  = 0xF
Rn   = 1
Rt   = 2
Rm   = 4
cond = 0xE
每条用例只修改 op1。由于 Rn=1，最后一组均进入 LDRSH immediate，不进入 literal 路径。
 
⸻

arm_instgrp_dataproc.073.R
Begin User Code
static struct vmm_vcpu vcpu;
static arch_regs_t regs;
static unsigned int inst;

memset(&vcpu, 0, sizeof(vcpu));
memset(&regs, 0, sizeof(regs));

/* op=0，op1=0x08，op2=0xF */
inst = 0xE00120F4U;
inst |= ((0x08U << ARM_INST_DATAPROC_OP1_SHIFT) &
         ARM_INST_DATAPROC_OP1_MASK);

<<emulate_arm.arm_instgrp_dataproc.inst>> = inst;
<<emulate_arm.arm_instgrp_dataproc.regs>> = &regs;
<<emulate_arm.arm_instgrp_dataproc.vcpu>> = &vcpu;

五、同步原语复合条件的缺失路径
该用例用于覆盖：
if (((op1 & 0x10) != 0) && (op2 == 0x9))
中的：
第一个条件 = true
第二个条件 = false
必须使用一个不会在前面的 switch(op2) 中直接返回的 op2。因此选择：
op1 = 0x10
op2 = 0x0

Begin User Code
static struct vmm_vcpu vcpu;
static arch_regs_t regs;
static unsigned int inst;

memset(&vcpu, 0, sizeof(vcpu));
memset(&regs, 0, sizeof(regs));

/*
 * op=0
 * op1=0x10：同步判断第一个条件为 true

<<emulate_arm.arm_instgrp_dataproc.regs>> = &regs;

每组中的 op1：
0x02、0x03、0x06、0x07、
