下面给出一版重新整理后的 vmm_scheduler.c 完整测试方案。这一版按你最新的 User Code 方案重新设计：
	1.	不在 Appendix 文件作用域使用 per_cpu() 初始化指针；
	2.	使用 VCAST_SCHED0 / VCAST_SCHED1 宏句柄；
	3.	对 rq_dequeue 使用 Stub End 强制输出同一个 VCPU 指针，避免 eventFlagObject 这种地址不一致问题；
	4.	对每个函数尽量做到 100% 覆盖；
	5.	对真正无法覆盖或受编译开关影响的分支给出说明；
	6.	尽量减少新增测试函数，只有一个可选 callback 函数用于覆盖 wq_cleanup 调用路径。
 
⸻
