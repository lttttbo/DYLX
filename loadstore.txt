下面这组先给 寄存器偏移半字 load/store 两个函数：
arm_inst_ldrh_r
arm_inst_strh_r
这组和上一组 ldrh_i / strh_i 的区别是：偏移不是立即数 imm4H/imm4L，而是来自 Rm 寄存器。
 
⸻
 
0. 公共说明
0.1 三个入参传递
每条用例都传：
<<emulate_arm.arm_inst_ldrh_r.inst>> = inst;
<<emulate_arm.arm_inst_ldrh_r.regs>> = &regs;
<<emulate_arm.arm_inst_ldrh_r.vcpu>> = &vcpu;
或：
<<emulate_arm.arm_inst_strh_r.inst>> = inst;
<<emulate_arm.arm_inst_strh_r.regs>> = &regs;
<<emulate_arm.arm_inst_strh_r.vcpu>> = &vcpu;
其中：
inst：手工构造的 32 bit 指令值
regs：static arch_regs_t regs
vcpu：static struct vmm_vcpu vcpu
0.2 每条用例公共模板
每条用例 Value User Code 先写：
static struct vmm_vcpu vcpu;
static arch_regs_t regs;
unsigned int inst;

memset(&vcpu, 0, sizeof(vcpu));
memset(&regs, 0, sizeof(regs));

vcpu.is_normal = 1U;
regs.pc = 0x1000U;
regs.pstate = 0U;

inst = 0U;
注意继续使用：
regs.pstate = ...
不要写：
arm_cpsr(&regs) = ...
0.3 寄存器偏移字段
ldrh_r / strh_r 用到这些字段：
cond   bits[31:28]
P      bit[24]
U      bit[23]
W      bit[21]
Rn     bits[19:16]
Rt     bits[15:12]
Rm     bits[3:0]
Rm 的设置方式：
inst |= (3U << ARM_INST_LDRSTR_RM_START);   /* Rm = 3 */
 
⸻
