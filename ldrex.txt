下面给下一组：
arm_inst_ldrex
arm_inst_strex
也就是 exclusive load/store。
这组有两个特点：
arm_inst_ldrex:
1. Rn 是基址寄存器。
2. Rt 是目标寄存器。
3. 调用 cpu_vcpu_mem_readex。
4. 成功后把读取数据写入 Rt。

arm_inst_strex:
1. Rn 是基址寄存器。
2. Rd 是状态结果寄存器，编码位置在 Rt 字段 bits[15:12]。
3. Rt 是源数据寄存器，编码位置在 Rm 字段 bits[3:0]。
4. 调用 cpu_vcpu_mem_writeex。
5. 成功后把 Rd 写为 0。
 
⸻
 
一、建议补充的简单 User Code 变量
如果你还没有给 readex/writeex 加打点，建议在 User Code -> Data 里加这几个基础变量：
unsigned int vcast_mem_readex_call;
unsigned int vcast_mem_readex_addr;
unsigned int vcast_mem_readex_size;
unsigned int vcast_mem_readex_priv;

unsigned int vcast_mem_writeex_call;
unsigned int vcast_mem_writeex_addr;
unsigned int vcast_mem_writeex_size;
unsigned int vcast_mem_writeex_priv;
在 Test Case Init 里加：
vcast_mem_readex_call = 0U;
vcast_mem_readex_addr = 0U;
vcast_mem_readex_size = 0U;
vcast_mem_readex_priv = 0U;

vcast_mem_writeex_call = 0U;
vcast_mem_writeex_addr = 0U;
vcast_mem_writeex_size = 0U;
vcast_mem_writeex_priv = 0U;
 
⸻
 
二、
cpu_vcpu_mem_readex
Stub 补充
如果你的 cpu_vcpu_mem_readex stub 当前只有返回值和写 dst，建议补成下面这样。参数名如果不同，按 VectorCAST stub 里的实际参数名替换。
extern unsigned int vcast_mem_readex_value;
extern int vcast_mem_readex_rc;

extern unsigned int vcast_mem_readex_call;
extern unsigned int vcast_mem_readex_addr;
extern unsigned int vcast_mem_readex_size;
extern unsigned int vcast_mem_readex_priv;

vcast_mem_readex_call++;
vcast_mem_readex_addr = address;
vcast_mem_readex_size = len;
vcast_mem_readex_priv = privileged;

if (dst != (void *)0) {
    *((unsigned int *)dst) = vcast_mem_readex_value;
}

return vcast_mem_readex_rc;
