一、补充遗漏：
arm_inst_ldr_l
arm_inst_ldr_l 是 word literal load。它没有 Rt 非法判断，Rt 即使为 15 也不会在本函数中进入不可预测分支。
使用字段：
cond   bits[31:28]
U      bit[23]
Rt     bits[15:12]
imm12  bits[11:0]
地址计算：
base = arm_align(regs.pc, 4)
U=1 -> address = base + imm12
U=0 -> address = base - imm12
公共模板：
static struct vmm_vcpu vcpu;
static arch_regs_t regs;
unsigned int inst;

memset(&vcpu, 0, sizeof(vcpu));
memset(&regs, 0, sizeof(regs));

vcpu.is_normal = 1U;
regs.pc = 0x1000U;
regs.pstate = 0U;

inst = 0U;
 
⸻
