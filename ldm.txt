下面继续 emulate_arm.c 中的：
arm_inst_ldm
按“最少用例覆盖全部可达分支”的原则，需要 9 条用例：
arm_inst_ldm.001.IN ～ arm_inst_ldm.003.IN
arm_inst_ldm.004.R
arm_inst_ldm.005.FI ～ arm_inst_ldm.006.FI
arm_inst_ldm.007.R ～ arm_inst_ldm.009.R
这 9 条同时覆盖：
Rn=15 / Rn!=15
reg_list=0 / reg_list!=0
wback=true / false
Rn 位于 reg_list / 不位于 reg_list
条件成立 / 不成立
increment / decrement
before / after
普通寄存器读取成功 / 失败
PC 读取成功 / 失败
reg_list bit15=true / false
写回 increment / decrement / 不写回
不需要新增 User Global、指令构造宏或调用打点。

arm_inst_ldm.001.IN
Begin User Code
static struct vmm_vcpu vcpu;
static arch_regs_t regs;
static unsigned int inst;

memset(&vcpu, 0, sizeof(vcpu));
memset(&regs, 0, sizeof(regs));

regs.pc = 0x1000ULL;

/*
 * cond     = 0xE
 * op       = 0x09：LDMIA，不写回
 * Rn       = 15
 * reg_list = R0
 */
inst = (0xEU << ARM_INST_COND_SHIFT) |
       (0x09U << ARM_INST_BRBLK_OP_START) |
       (15U << ARM_INST_LDMSTM_RN_START) |
       0x0001U;

<<emulate_arm.arm_inst_ldm.inst>> = inst;
<<emulate_arm.arm_inst_ldm.regs>> = &regs;
<<emulate_arm.arm_inst_ldm.vcpu>> = &vcpu;
期望值
return = VMM_EFAIL
regs.pc = 0x1000
注释
测试目的：验证基址寄存器 Rn=15 时，函数将 LDM 指令判定为不可预测并返回失败。 用例类别：接口测试 预置条件：构造有效的 VCPU 和寄存器对象；设置非空寄存器列表；设置基址寄存器为 R15。 测试步骤： step1、清零 VCPU 和寄存器对象。 step2、设置初始 PC 为 0x1000。 step3、构造 Rn=15、reg_list=R0 的 LDMIA 指令。 step4、调用 arm_inst_ldm。 step5、观察函数返回值和 PC。 用例来源：接口分析。 追踪ID：arm_inst_ldm。 等价列表：非法基址寄存器 R15。 其它说明：覆盖判断 (Rn == 15) || (!reg_list) 中第一个条件为 true 的路径。寄存器列表设置为非空，保证失败原因仅为 Rn=15。 通过准则：函数返回 VMM_EFAIL，PC 保持 0x1000。

三、覆盖对应关系
代码路径	对应用例
Rn==15	001.IN
Rn!=15 && reg_list==0	002.IN
wback && Rn在reg_list中	003.IN
wback=false 的短路路径	004.R、007.R
条件不成立	004.R
increment-after	005.FI
decrement-before	006.FI
普通寄存器读取失败	005.FI
PC 读取失败	006.FI
普通寄存器读取成功	007.R、008.R、009.R
PC 读取成功	007.R
reg_list bit15=false	008.R、009.R
reg_list bit15=true	006.FI、007.R
不写回	007.R
increment-before 并写回	008.R
decrement-after 并写回	009.R
这 9 条已覆盖 arm_inst_ldm 中全部可达判断结果和错误返回路径。
