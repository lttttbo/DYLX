下面给你一版基于当前极简 User Code 原则重新整理的完整方案。重点是：
	1.	不再定义全局 vcast_arm_vcpu、vcast_arm_regs、vcast_cp；
	2.	每条用例自己在 Value User Code 中定义 static struct vmm_vcpu vcpu; static arch_regs_t regs;；
	3.	User Code 只保留基础变量和必要 stub 打点；
	4.	不额外定义一堆宏和 fixture reset 函数；
	5.	所有 if/条件判断尽量双侧覆盖；
	6.	确实无法覆盖的 dead code 单独说明。
 
⸻

三、通用用例局部构造模板
每条指令函数用例的 Value User Code 采用这个模板：
static struct vmm_vcpu vcpu;
static arch_regs_t regs;
unsigned int inst;

memset(&vcpu, 0, sizeof(vcpu));
memset(&regs, 0, sizeof(regs));

vcpu.is_normal = 1U;
arm_pc(&regs) = 0x1000U;
arm_cpsr(&regs) = 0U;

inst = 0U;

/* cond = AL */
inst |= (0xEU << ARM_INST_COND_SHIFT);

/* 下面按具体函数设置字段 */

<<emulate_arm.<函数名>.inst>> = inst;
<<emulate_arm.<函数名>.regs>> = &regs;
<<emulate_arm.<函数名>.vcpu>> = &vcpu;
如果要构造条件不成立：
inst |= (0x0U << ARM_INST_COND_SHIFT);  /* EQ */
arm_cpsr(&regs) = 0U;                   /* Z = 0，所以 EQ 不成立 */
如果要构造条件成立：
inst |= (0xEU << ARM_INST_COND_SHIFT);  /* AL */

十二、Coprocessor 函数
重要说明
如果只覆盖空回调路径，不需要新增函数。cpu_vcpu_coproc_get Stub 里返回一个静态空 struct cpu_vcpu_coproc 即可：
static struct cpu_vcpu_coproc cp;

memset(&cp, 0, sizeof(cp));

return &cp;
但要覆盖 coprocessor 成功路径，必须给函数指针赋真实回调函数。这是唯一无法完全避免新增测试函数的部分。

十七、Dead Code / 覆盖率排除
1. 
arm_inst_movw_i
源码中：
if (Rd == 15) {
    arm_unpredictable(...);
    return VMM_EFAIL;
}
...
if (arm_condition_passed(cond, regs)) {
    if (Rd == 15) {
        arm_pc(regs) = result;
    } else {
        cpu_vcpu_reg_write(...);
    }
}
内部的：
if (Rd == 15)
不可达，因为前面已经返回。
 
排除说明：
`arm_inst_movw_i` 中 condition passed 内部的 `if (Rd == 15)` 分支不可达。函数前部已经对 `Rd == 15` 执行不可预测处理并返回，后续相同条件不可能再次成立，属于源代码逻辑 dead code，应从覆盖率中排除。
 
⸻
 
2. 
emulate_arm_inst
switch (op1 & 0x6) {
case 0x0:
case 0x2:
case 0x4:
case 0x6:
default:
}
op1 & 0x6 只能是 0x0/0x2/0x4/0x6，default 不可达。
 
排除说明：
`emulate_arm_inst` 中 `switch (op1 & 0x6)` 的 default 分支不可达，因为按位与 `0x6` 的结果只能为 0x0、0x2、0x4、0x6。该 default 属于防御性 dead code，应从覆盖率中排除。
 
⸻
 
3. 
arm_decode_imm_shift
源码中 return 后面的 break 不可达：
return imm5;
break;
如果 VectorCAST 把这些 break 标红，应排除。
 
排除说明：
`arm_decode_imm_shift` 中多个 case 的 `break` 位于 `return` 语句之后，执行流不可能到达，属于 return 后不可达语句，应从覆盖率中排除。
 
⸻
