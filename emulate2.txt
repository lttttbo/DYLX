已更正：本文件单元名为 cpu_vcpu_emulate。下面的 VectorCAST 参数绑定统一使用：
<<cpu_vcpu_emulate.函数名.参数名>>
本批包含：
cpu_vcpu_emulate_mcr_mrc_cp15
cpu_vcpu_emulate_mcr_mrc_cp14
vcpu_advance_pc
cpu_vcpu_emulate_load
按决策覆盖和条件覆盖计算，建议的最少用例数为：
CP15：5 条
CP14：5 条
vcpu_advance_pc：ARM64 配置下 3 条
cpu_vcpu_emulate_load：10 条
其中 cpu_vcpu_emulate_load 的 switch default 是否不可达，需要结合 ISS_ABORT_SAS_MASK 的实际定义最终确认。若该字段是标准 2-bit SAS 字段，则 sas 只能为 0～3，default 属于不可达代码。

if (vcast_load_read_rc != VMM_OK) {
    return vcast_load_read_rc;
}

switch (len) {
case 1U:
    *(u8 *)dst = (u8)vcast_load_read_value;
    break;
case 2U:
    *(u16 *)dst = (u16)vcast_load_read_value;
    break;
case 4U:
    *(u32 *)dst = (u32)vcast_load_read_value;
    break;
case 8U:
    *(u64 *)dst = (u64)vcast_load_read_value;
    break;
default:
    break;
}

return VMM_OK;

七、不可达代码说明
cpu_vcpu_emulate_load 中：
default:
    rc = VMM_EFAIL;
    break;
是否不可达取决于：
ISS_ABORT_SAS_MASK
ISS_ABORT_SAS_SHIFT
若定义为标准 2-bit SAS 字段，则：
sas = (iss & ISS_ABORT_SAS_MASK) >> ISS_ABORT_SAS_SHIFT;
只能得到：
0、1、2、3
因此 default 不可达，可作为 dead code / unreachable 说明。
 
若需要最终确认，请提供：
ISS_ABORT_SAS_MASK
ISS_ABORT_SAS_SHIFT
的实际定义。
