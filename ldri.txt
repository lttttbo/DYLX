下面这一组是普通 word / byte immediate load/store：
arm_inst_ldr_i
arm_inst_str_i
arm_inst_ldrb_i
arm_inst_strb_i
每条用例先使用公共模板：
static struct vmm_vcpu vcpu;
static arch_regs_t regs;
unsigned int inst;

memset(&vcpu, 0, sizeof(vcpu));
memset(&regs, 0, sizeof(regs));

vcpu.is_normal = 1U;
regs.pc = 0x1000U;
regs.pstate = 0U;

inst = 0U;
字节写入用例里，如果要验证：
vcast_mem_write_value_seq[0] = 0x78
请确认你的 cpu_vcpu_mem_write stub 是按 len 读取 src 的，例如 len==1 时按 u8 * 取值，len==4 时按 u32 * 取值。否则字节写入的记录值可能不稳定。
 
⸻
 
一、
arm_inst_ldr_i
arm_inst_ldr_i.001.R
覆盖：
P=1,U=1,W=0
index=true
add=true
wback=false
condition true by AL
mem_read success
构造代码
inst = 0xE1812010U;

vcast_reg_read_value[1] = 0x2000U;

vcast_mem_read_value_seq[0] = 0x12345678U;
vcast_mem_read_rc_seq[0] = 0;

<<emulate_arm.arm_inst_ldr_i.inst>> = inst;
<<emulate_arm.arm_inst_ldr_i.regs>> = &regs;
<<emulate_arm.arm_inst_ldr_i.vcpu>> = &vcpu;
期望值
return = 0
regs.pc = 0x1004

vcast_mem_read_call = 1
vcast_mem_read_addr_seq[0] = 0x2010
vcast_mem_read_size_seq[0] = 4

vcast_reg_write_called[1] = 0
vcast_reg_write_called[2] = 1
vcast_reg_write_value[2] = 0x12345678
注释
测试目的：验证 ldr immediate 在 pre-index add 且不写回时，能够读取 word 并写入 Rt。 用例类别：基于需求的测试 预置条件：构造有效 VCPU 和寄存器对象；设置 R1 返回 0x2000；设置内存读取返回 0x12345678。 测试步骤： step1、构造 inst=0xE1812010。 step2、该指令解码后 P=1、U=1、W=0、Rn=1、Rt=2、imm32=0x10。 step3、调用 arm_inst_ldr_i。 step4、观察返回值、PC、内存读取地址和 Rt 写入值。 用例来源：需求分析、有效等价类 追溯ID：arm_inst_ldr_i 等价列表：pre-index add、无写回、条件成立、读取成功。 其它说明：覆盖 index=true、add=true、wback=false 正常路径。 通过准则：返回 0；PC 为 0x1004；读取地址为 0x2010；R2 写入 0x12345678；R1 不写回。
