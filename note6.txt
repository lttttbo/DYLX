下面按你现在的要求生成 vmm_waitqueue.c 的单元测试设计：
	•	每个函数独立设计用例；
	•	每条用例包含：具体构造方法、Expected return、关键期望、可复制注释；
	•	注释里的 step1/step2/step3 分行写；
	•	BUG_ON 按你说的方式处理：if (x) exit(0)；
	•	不通过外层接口间接覆盖内部函数，static 函数单独给用例。

⸻

一、公共 User Code 设置

1. Unit Prefix User Code / Prefix User Code

放到你当前能影响 vmm_waitqueue.c 的 Prefix 位置。

#include <vmm_waitqueue.h>
#include <vmm_timer.h>
#include <vmm_scheduler.h>

#ifdef BUG_ON
#undef BUG_ON
#endif

#define BUG_ON(x)              \
    do {                       \
        if (x) {               \
            exit(0);           \
        }                      \
    } while (0)

/*
 * vmm_waitqueue.c 内部定义了：
 * struct vmm_waitqueue_priv {
 *     struct vmm_waitqueue *wq;
 *     struct vmm_timer_event *ev;
 * };
 *
 * 该类型是 .c 内部类型，driver 侧可能不可见。
 * 这里定义同布局测试结构，用于赋给 vcpu->wq_priv。
 */
struct vcast_wq_priv {
    struct vmm_waitqueue *wq;
    struct vmm_timer_event *ev;
};

static struct vcast_wq_priv vcast_wq_priv_obj;

extern unsigned int vcast_wq_cleanup_called;

static void vcast_wq_cleanup_cb(struct vmm_vcpu *vcpu)
{
    (void)vcpu;
    vcast_wq_cleanup_called++;
}


⸻

2. User Globals

unsigned int vcast_wq_cleanup_called;


⸻

3. Test Case Init

vcast_wq_cleanup_called = 0U;

4. 锁相关函数

以下函数建议作为 no-op stub，避免真实锁或架构汇编：

vmm_spin_lock_irq
vmm_spin_unlock_irq
vmm_spin_lock_irqsave
vmm_spin_unlock_irqrestore

如果它们不是 stub，可以在 Prefix 里做 no-op 宏替换。
