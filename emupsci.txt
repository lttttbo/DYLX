下面给 psci.c 的单元测试构造方案。重点按你之前的原则来：
	1.	尽量少写辅助函数。
	2.	User Global 里只放简单变量，不放完整结构体对象。
	3.	需要遍历 guest vcpu 的地方，用宏重定义成可控数组遍历。
	4.	返回值能够证明路径时，不额外验证某个 helper 是否被调用。
	5.	if / 条件表达式尽量覆盖 true / false。
	6.	switch case 如果 VectorCAST 单独统计 case label，则每个 case label 要单独建用例。
 
⸻
 
一、最小 User Code / Stub 方案
1. User Global / Data
放这些简单变量：
void *vcast_psci_vcpus[4];
unsigned int vcast_psci_vcpu_count;
unsigned int vcast_psci_iter_idx;

unsigned long vcast_psci_reg[8];
unsigned long vcast_psci_set_reg_value[8];

unsigned long vcast_psci_mpidr[4];
unsigned int vcast_psci_state[4];

unsigned int vcast_psci_version;
unsigned int vcast_psci_is_32bit;
unsigned int vcast_psci_is_be;

int vcast_psci_vcpu_reset_rc;
int vcast_psci_vcpu_kick_rc;
int vcast_psci_guest_shutdown_rc;
int vcast_psci_guest_reboot_rc;
int vcast_psci_guest_suspend_rc;
 
⸻
 
2. Unit Prefix User Code
用于控制：
vmm_manager_for_each_guest_vcpu(tmp, guest)
否则 psci_vcpu_on、psci_vcpu_affinity_info、psci_system_suspend 不好稳定构造。
#undef vmm_manager_for_each_guest_vcpu
#define vmm_manager_for_each_guest_vcpu(_vcpu, _guest)                 \
    for (vcast_psci_iter_idx = 0U;                                     \
         (vcast_psci_iter_idx < vcast_psci_vcpu_count) &&              \
         (((_vcpu) = (struct vmm_vcpu *)vcast_psci_vcpus[vcast_psci_iter_idx]) != 0); \
         vcast_psci_iter_idx++)
如果你的 VectorCAST 环境里 Unit Prefix User Code 太晚，导致这个宏没有影响源码，请把这段放到更早的 Driver Prefix User Code 或 Unit Prefix File Code，总之必须在被测源文件展开该宏之前生效。
 
⸻

二、公共对象模板
大多数用例可以用下面模板：
static struct vmm_vcpu src;
static struct vmm_vcpu tgt;
static struct vmm_vcpu other;
static struct vmm_guest guest;
static arch_regs_t regs;

memset(&src, 0, sizeof(src));
memset(&tgt, 0, sizeof(tgt));
memset(&other, 0, sizeof(other));
memset(&guest, 0, sizeof(guest));
memset(&regs, 0, sizeof(regs));

src.guest = &guest;
tgt.guest = &guest;
other.guest = &guest;

regs.pc = 0x1000U;
regs.pstate = 0U;
如果 struct vmm_guest 在测试代码处不可见，可以先把涉及 guest->name 的错误分支推迟，或者把 guest 对象定义放在 Unit Prefix 里并暴露指针。

psci_affinity_mask.001.R.level0
构造：
<<psci.psci_affinity_mask.affinity_level>> = 0UL;
期望：
return = MPIDR_HWID_BITMASK
注释：
测试目的：验证 affinity level 为 0 时返回有效 affinity mask。 用例类别：基于需求的测试 预置条件：无。 测试步骤： step1、设置 affinity_level=0。 step2、调用 psci_affinity_mask。 step3、观察返回值。 用例来源：边界值测试 追溯ID：psci_affinity_mask 等价列表：有效 affinity level 下界。 其它说明：覆盖 affinity_level <= 3 为 true 的路径。 通过准则：返回值等于 MPIDR_HWID_BITMASK & AFFINITY_MASK(0)，也就是 MPIDR_HWID_BITMASK。
