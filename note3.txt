下面按你确认的格式输出：每个函数独立设计，不通过外层接口间接覆盖内部函数；每个用例包含具体构造方法和可复制的用例注释。

如果它们在 Stub List 中，保持默认返回即可；如果被真实展开到架构汇编，建议在 Unit Prefix User Code -> vmm_semaphore 中做 no-op 宏替换。

3. __vmm_semaphore_cleanup

源码中：

struct vmm_semaphore_resource *sres =
    container_of(vcpu_res, struct vmm_semaphore_resource, res);
struct vmm_semaphore *sem = sres->sem;
if (!sres || !sem || (sres->vcpu != vcpu)) {
    return;
}

注意：vcpu_res == NULL 会先参与 container_of，不建议普通运行该用例。

6. vmm_semaphore_up

需要覆盖：
	•	value < limit；
	•	value >= limit；
	•	当前 VCPU 有资源；
	•	当前 VCPU 无资源但有第一个资源；
	•	没有资源；
	•	sres->count 递减后为 0；
	•	sres->count 递减后仍非 0；
