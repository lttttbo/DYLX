下面这一组给：
arm_inst_ldrd_l
arm_inst_ldrd_r
arm_inst_strd_r
其中 arm_inst_ldrd_l 是 literal doubleword load；arm_inst_ldrd_r / arm_inst_strd_r 是 register offset doubleword load/store。
这组我会继续按“尽量最少用例覆盖完整分支”的思路设计；其中容易出错的分支直接使用固定 inst 值，避免字段拼错。
 
⸻
 
一、公共模板
每条用例 Value User Code 先写：
static struct vmm_vcpu vcpu;
static arch_regs_t regs;
unsigned int inst;

memset(&vcpu, 0, sizeof(vcpu));
memset(&regs, 0, sizeof(regs));

vcpu.is_normal = 1U;
regs.pc = 0x1000U;
regs.pstate = 0U;

inst = 0U;
 
⸻
 
二、
arm_inst_ldrd_l
arm_inst_ldrd_l 字段：
cond   bits[31:28]
U      bit[23]
Rt     bits[15:12]
imm4H  bits[11:8]
imm4L  bits[3:0]
地址计算：
base = arm_align(regs.pc, 4)
U=1 -> address = base + imm32
U=0 -> address = base - imm32
 
⸻

五、本组说明
这一组里 arm_inst_ldrd_r / arm_inst_strd_r 不建议再用移位拼字段，原因是条件组合太多，Rt/Rm/Rn 很容易互相短路。固定值更稳。
本组覆盖点包括：
ldrd_l:
Rt 奇数
Rt==14
U=1 add
U=0 sub
condition true / false
第一次读取失败
第二次读取失败
两次读取成功

ldrd_r:
Rt 奇数
P=0,W=1
Rt==14
Rm==15
Rm==Rt
Rm==Rt+1
wback && Rn==15
wback && Rn==Rt
wback && Rn==Rt+1
index/add true
index/add false
condition false
第一次读取失败
第二次读取失败

strd_r:
Rt 奇数触发 undefined irq
P=0,W=1
Rt==14
Rm==15
wback && Rn==15
wback && Rn==Rt
wback && Rn==Rt+1
index/add true
index/add false
condition false
第一次写失败
第二次写失败
下一组建议进入普通 word/byte load/store：
arm_inst_ldr_i
arm_inst_str_i
arm_inst_ldrb_i
arm_inst_strb_i
这一组分支也多，但比 doubleword 稍简单。
