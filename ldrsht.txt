下面给下一组：signed T 类 load 两个接口：
arm_inst_ldrsht
arm_inst_ldrsbt
它们和上一组 ldrht / strht 的字段规则一致：
REGFORM1 = 0 -> regform = TRUE，使用 Rm 作为 offset
REGFORM1 = 1 -> regform = FALSE，使用 imm4H/imm4L 作为 offset
区别是：
arm_inst_ldrsht：读取 2 字节，执行 16 位符号扩展
arm_inst_ldrsbt：读取 1 字节，执行 8 位符号扩展
每条用例先使用公共模板：
static struct vmm_vcpu vcpu;
static arch_regs_t regs;
unsigned int inst;

memset(&vcpu, 0, sizeof(vcpu));
memset(&regs, 0, sizeof(regs));

vcpu.is_normal = 1U;
regs.pc = 0x1000U;
regs.pstate = 0U;

inst = 0U;
下面期望中的：
vcast_mem_read_priv_seq[0] = 1
用于确认 cpu_vcpu_mem_read(..., TRUE)。如果你当前 stub 没记录 privileged 参数，可以先不填这项期望。

arm_inst_ldrsht.001.R
构造代码
/* cond = AL */
inst |= (0xEU << ARM_INST_COND_SHIFT);

/* U=1, REGFORM1=0 -> regform = TRUE */
inst |= (1U << ARM_INST_LDRSTR_U_START);

/* Rn=1, Rt=2, Rm=3 */
inst |= (1U << ARM_INST_LDRSTR_RN_START);
inst |= (2U << ARM_INST_LDRSTR_RT_START);
inst |= (3U << ARM_INST_LDRSTR_RM_START);

vcast_reg_read_value[1] = 0x2000U;
vcast_reg_read_value[3] = 0x10U;

vcast_mem_read_value_seq[0] = 0x8001U;
vcast_mem_read_rc_seq[0] = 0;

<<emulate_arm.arm_inst_ldrsht.inst>> = inst;
<<emulate_arm.arm_inst_ldrsht.regs>> = &regs;
<<emulate_arm.arm_inst_ldrsht.vcpu>> = &vcpu;

注释
测试目的：验证 ldrsht 在寄存器偏移形式、U 位为 1 时，能够从原始 Rn 地址读取半字，并进行 16 位符号扩展后写入 Rt，同时将 Rn 写回为 Rn 加 Rm 偏移后的地址。 用例类别：基于需求的测试 预置条件：构造有效 VCPU 和寄存器对象；设置 Rn 读返回 0x2000；设置 Rm 读返回 0x10；设置内存读取返回 0x8001。 测试步骤： step1、构造 inst，设置条件码为 AL。 step2、设置 REGFORM1=0，使指令进入寄存器偏移形式。 step3、设置 U=1、Rn=1、Rt=2、Rm=3。 step4、设置 R1 返回 0x2000，R3 返回 0x10。 step5、设置 cpu_vcpu_mem_read 第一次读取返回 0x8001。 step6、调用 arm_inst_ldrsht。 step7、观察返回值、PC、内存读取地址、Rn 写回值和 Rt 写入值。 用例来源：需求分析、有效等价类 追溯ID：arm_inst_ldrsht 等价列表：寄存器偏移形式、U=1、条件成立、内存读取成功、16 位符号位为 1。 其它说明：本用例覆盖 regform=true、add=true、条件成立、内存读取成功和 16 位符号扩展路径。 通过准则：函数返回 0；PC 更新为 0x1004；内存读取地址为 0x2000；R1 写回 0x2010；R2 写入 0xFFFF8001。
