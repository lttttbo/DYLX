下面给下一组：signed immediate load 两个接口：
arm_inst_ldrsh_i
arm_inst_ldrsb_i
它们都是 immediate 形式，字段和 ldrh_i 一样：
cond   bits[31:28]
P      bit[24]
U      bit[23]
W      bit[21]
Rn     bits[19:16]
Rt     bits[15:12]
imm4H  bits[11:8]
imm4L  bits[3:0]
区别是：
arm_inst_ldrsh_i：读取 2 字节，调用 arm_sign_extend(data, 16, 32)
arm_inst_ldrsb_i：读取 1 字节，调用 arm_sign_extend(data, 8, 32)
每条用例都先使用这个公共模板：
static struct vmm_vcpu vcpu;
static arch_regs_t regs;
unsigned int inst;

memset(&vcpu, 0, sizeof(vcpu));
memset(&regs, 0, sizeof(regs));

vcpu.is_normal = 1U;
regs.pc = 0x1000U;
regs.pstate = 0U;

inst = 0U;

arm_inst_ldrsh_i.001.R

P=1, U=1, W=0
index=true
add=true
wback=false
condition=true
mem_read success
16-bit sign extend

/* cond = AL */
inst |= (0xEU << ARM_INST_COND_SHIFT);

/* P=1, U=1, W=0 */
inst |= (1U << ARM_INST_LDRSTR_P_START);

/* Rn=1, Rt=2 */
inst |= (1U << ARM_INST_LDRSTR_RN_START);
inst |= (2U << ARM_INST_LDRSTR_RT_START);

/* imm4H=1, imm4L=0, imm32=0x10 */
inst |= (1U << ARM_INST_LDRSTR_IMM4H_START);

vcast_reg_read_value[1] = 0x2000U;

vcast_mem_read_value_seq[0] = 0x8001U;
vcast_mem_read_rc_seq[0] = 0;

<<emulate_arm.arm_inst_ldrsh_i.inst>> = inst;
<<emulate_arm.arm_inst_ldrsh_i.regs>> = &regs;
<<emulate_arm.arm_inst_ldrsh_i.vcpu>> = &vcpu;

注释
测试目的：验证 ldrsh immediate 在 pre-index add 且不写回时，能够读取半字并进行 16 位符号扩展后写入目标寄存器。 用例类别：基于需求的测试 预置条件：构造有效 VCPU 和寄存器对象；设置 Rn 读返回 0x2000；设置内存读取返回 0x8001。 测试步骤： step1、构造 inst，设置条件码为 AL。 step2、设置 P=1、U=1、W=0。 step3、设置 Rn=1、Rt=2、imm32=0x10。 step4、设置 R1 返回 0x2000。 step5、设置 cpu_vcpu_mem_read 第一次读取返回 0x8001。 step6、调用 arm_inst_ldrsh_i。 step7、观察返回值、PC、内存读取地址、Rn 写回情况和 Rt 写入值。 用例来源：需求分析、有效等价类 追溯ID：arm_inst_ldrsh_i 等价列表：pre-index add、无写回、条件成立、符号位为 1。 其它说明：本用例覆盖 index=true、add=true、wback=false 以及 16 位符号扩展路径。 通过准则：函数返回 0；PC 更新为 0x1004；内存读取地址为 0x2010；R1 不写回；R2 写入 0xFFFF8001。
