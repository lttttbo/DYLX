2. 更新

该函数需要初始化 mngr.guest_list，并将 guest_count 个已占用 Guest 加入链表，供 Guest 重复检查使用：
void vcast_manager_prepare_guest_env(u32 guest_count)
{
    u32 g;

    memset(vcast_guest_array,
           0,
           sizeof(vcast_guest_array));

    memset(vcast_guest_avail_array,
           0,
           sizeof(vcast_guest_avail_array));

    memset(vcast_guest_work_store,
           0,
           sizeof(vcast_guest_work_store));

    INIT_LIST_HEAD(&mngr.guest_list);

    for (g = 0U;
         g < (u32)CONFIG_MAX_GUEST_COUNT;
         ++g) {
        INIT_LIST_HEAD(&vcast_guest_array[g].head);

        vcast_guest_array[g].id = g;
        vcast_guest_avail_array[g] = TRUE;

        if (g < guest_count) {
            vcast_guest_avail_array[g] = FALSE;

            list_add_tail(
                &vcast_guest_array[g].head,
                &mngr.guest_list);
        }
    }

    mngr.guest_array = vcast_guest_array;
    mngr.guest_avail_array =
        vcast_guest_avail_array;

    mngr.guest_work_array =
        &vcast_guest_work_store[1];

    mngr.guest_count = guest_count;

    vcast_expected_guest = NULL;
}

 * vmm_cpumask_set_cpu 是 static inline 函数，不能直接 Stub。

 * 在 vmm_cpumask.h 已完成 inline 函数定义后，使用同名函数式宏

    do {                                     \
        (void)(cpu);                         \
        (void)(dstp);                        \
    } while (0)

 * 隔离真实设备树子节点链表。
 *
 * vcast_dt_child == NULL：

#endif

十二、不可达路径说明
1. 最小优先级判断 true 不可达
源码：
if (vcpu->priority < VMM_VCPU_MIN_PRIORITY)
当前定义：
#define VMM_VCPU_MIN_PRIORITY 0
而：
vcpu->priority
类型是 u8，其最小值也是 0，因此不存在：
priority < 0
的合法输入。该判断 true 路径结构性不可达。
 
⸻
 
2. 
!guest
子条件通常不可独立为 true
源码：
if (!guest ||
    gnum == (u32)CONFIG_MAX_GUEST_COUNT)
前面执行了：
list_for_each_entry(guest, &mngr.guest_list, head)
常见链表宏即使在空链表上，也会把 guest 计算为基于链表头的哨兵容器地址，而不是保留为 NULL。
因此无可用 Guest 时通常得到：
!guest = false
gnum == CONFIG_MAX_GUEST_COUNT = true
整体判断仍为 true，但 !guest=true 的独立条件结果通常不可通过合法链表环境构造。
 
⸻
 
3. 
CONFIG_CPU_BE
是编译期路径
#ifdef CONFIG_CPU_BE
    guest->is_big_endian = TRUE;
#else
    guest->is_big_endian = FALSE;
#endif
一次构建中只编译其中一条语句，不能通过运行时用例覆盖另一个编译配置。
 
⸻
