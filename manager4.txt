六、不可行条件说明
vmm_manager_vcpu_set_affinity() 中：
if (!(vmm_cpumask_subset(cpu_mask, domain_mask)) &&
    !vmm_cpumask_equal(cpu_mask, domain_mask)) {
若覆盖工具显示第二个条件：
!vmm_cpumask_equal(...) == false
未覆盖，这是结构性不可行结果。
原因是第二个条件只有在：
vmm_cpumask_subset(...) == false
时才会求值；但两个掩码相等必然意味着前者是后者的子集。因此不存在：
subset == false
equal == true
的合法掩码组合。当前用例已覆盖：
subset == true                    -> 短路，不执行 equal
subset == false、equal == false  -> 返回 VMM_EFAIL
除这一不可行条件组合外，上述 3 + 9 + 7 = 19 条用例覆盖了三个函数的全部可达语句、分支和短路条件结果。
