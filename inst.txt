下面先给两部分：
1. emulate_arm_inst 的完整用例构造和注释
2. 我新增的辅助函数的独立用例构造和注释
辅助函数这部分按“简单覆盖即可”的原则，不再验证某个函数是否被调用，只验证返回值或输出变量；空实现函数只做入口覆盖。

emulate_arm_inst
不可达说明
switch (op1 & 0x6) {
case 0x0:
case 0x2:
case 0x4:
case 0x6:
default:
    break;
}
这里 op1 & 0x6 的结果只能是：
0x0, 0x2, 0x4, 0x6
所以 default 分支是不可达代码。如果 VectorCAST 显示该 default 或 switch 之后的最终 arm_unpredictable 未覆盖，应作为源码不可达分支记录。

三、本批覆盖关系
emulate_arm_inst 覆盖：
vcpu == NULL
vcpu->is_normal == false
cond != 0xF
cond == 0xF
case 0x0 dataproc
case 0x2 ldrstr first condition
case 0x2 ldrstr second condition
case 0x2 media
case 0x4 brblk
case 0x6 coproc
不可达：
switch (op1 & 0x6) 的 default 不可达
switch 后最终 arm_unpredictable 理论不可达
辅助函数覆盖：
accept true / false
done true / false
read 数组取值
write 空实现入口
write2 true / false
read2 指针非空 / 指针为空
data_process true / false
write true / false
read 指针非空 / 指针为空
vcast_get_cp mask 全 true / 全 false
接下来剩余主要是：
arm_instgrp_coproc
arm_instgrp_ldrstr
这两个是最后的大分派函数。
