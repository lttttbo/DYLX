明白，按以下原则重新构造：
	•	当前单元为 emulate_arm.c，参数路径使用 <<emulate_arm...>>。
	•	不新增 User Global。
	•	不新增指令构造宏。
	•	指令在每条测试的 Begin User Code 中直接按位构造。
	•	不对 cpu_vcpu_reg_read/write、arm_unpredictable、IRQ 注入等中间调用打点。
	•	不验证中间寄存器写入值和内存访问地址，只验证能区分控制流的函数返回值和 regs.pc。
	•	arm_inst_strd_i 只补图中缺失的 add=false 和 index=false 路径。
	•	arm_inst_ldrd_r、arm_inst_strd_r 按条件覆盖完整给出。
