下一组是 unprivileged T 类普通 word/byte load/store：
arm_inst_ldrt
arm_inst_strt
arm_inst_ldrbt
arm_inst_strbt
这组有几个共同点：
REGFORM2 bit[25] = 1：寄存器偏移形式，offset 来自 Rm。
REGFORM2 bit[25] = 0：立即数偏移形式，offset 来自 imm12。

U = 1：offset_addr = address + offset。
U = 0：offset_addr = address - offset。

内存访问地址始终使用原始 Rn 地址。
offset_addr 只用于写回 Rn。
内存访问最后一个参数均为 TRUE。
每条用例 Value User Code 先使用公共模板：
static struct vmm_vcpu vcpu;
static arch_regs_t regs;
unsigned int inst;

memset(&vcpu, 0, sizeof(vcpu));
memset(&regs, 0, sizeof(regs));

vcpu.is_normal = 1U;
regs.pc = 0x1000U;
regs.pstate = 0U;

inst = 0U;
如果你的 stub 没有记录 privileged 参数，下面期望里的 vcast_mem_read_priv_seq[0]、vcast_mem_write_priv_seq[0] 可以先不填。
 
⸻

arm_inst_ldrt
arm_inst_ldrt.001.R
构造代码
/*
 * cond=AL
 * REGFORM2=1，寄存器偏移形式
 * U=1
 * Rn=1, Rt=2, Rm=4
 */
inst = 0xE2812004U;

vcast_reg_read_value[1] = 0x2000U;
vcast_reg_read_value[4] = 0x10U;

vcast_mem_read_value_seq[0] = 0x12345678U;
vcast_mem_read_rc_seq[0] = 0;

<<emulate_arm.arm_inst_ldrt.inst>> = inst;
<<emulate_arm.arm_inst_ldrt.regs>> = &regs;
<<emulate_arm.arm_inst_ldrt.vcpu>> = &vcpu;
期望值
return = 0
regs.pc = 0x1004

vcast_mem_read_call = 1
vcast_mem_read_addr_seq[0] = 0x2000
vcast_mem_read_size_seq[0] = 4
vcast_mem_read_priv_seq[0] = 1

vcast_reg_write_called[1] = 1
vcast_reg_write_value[1] = 0x2010

vcast_reg_write_called[2] = 1
vcast_reg_write_value[2] = 0x12345678
注释
测试目的：验证 ldrt 在寄存器偏移形式、U 位为 1 时，从原始 Rn 地址读取 word，并将 Rn 写回为 Rn 加 Rm 偏移后的地址。 用例类别：基于需求的测试 预置条件：设置 R1 返回 0x2000，R4 返回 0x10；设置内存读取返回 0x12345678。 测试步骤： step1、构造 inst=0xE2812004。 step2、该指令解码后 REGFORM2=1、U=1、Rn=1、Rt=2、Rm=4。 step3、调用 arm_inst_ldrt。 step4、观察返回值、PC、内存读取地址、Rn 写回值和 Rt 写入值。 用例来源：需求分析、有效等价类 追溯ID：arm_inst_ldrt 等价列表：寄存器偏移形式、U=1、条件成立、读取成功。 其它说明：覆盖 regform=true、add=true、条件成立、读取成功路径。 通过准则：返回 0；PC 为 0x1004；读取地址为 0x2000；R1 写回 0x2010；R2 写入 0x12345678。
