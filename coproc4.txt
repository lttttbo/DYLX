继续 emulate_arm.c 中 arm_instgrp_coproc 的通用协处理器分支，本批覆盖：
cpro != 0xA 且 cpro != 0xB
op1 = 0x20 ～ 0x3F
正式编号：
arm_instgrp_coproc.097.R ～ arm_instgrp_coproc.128.R
本批不增加任何 User Global、指令构造宏或调用打点。所有用例都不设置 CPRO 字段，因此：
cpro = 0
稳定进入：
default: /* Generic coprocessor instructions */
分派安排如下：
用例	op1	OP	分派函数
.097.R	0x20	0	arm_inst_cdpx
.098.R	0x21	0	arm_inst_cdpx
.099.R～.112.R	0x22～0x2F	1	偶数进入 arm_inst_mcrx，奇数进入 arm_inst_mrcx
.113.R～.128.R	0x30～0x3F	任意	arm_inst_svc
这样同时覆盖两个 if (inst & ARM_INST_COPROC_OP_MASK) 判断的 true 和 false。
 
⸻
 
一、CDP、MCR、MRC 分派

static struct vmm_vcpu vcpu;
static arch_regs_t regs;
static unsigned int inst;

 * cpro = 0
 * op1  = 0x20
 * OP   = 0
 */

        ARM_INST_COPROC_OP1_MASK);

<<emulate_arm.arm_instgrp_coproc.inst>> = inst;
<<emulate_arm.arm_instgrp_coproc.regs>> = &regs;
