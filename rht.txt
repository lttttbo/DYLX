下面给下一组：半字 T 指令，两个接口：
arm_inst_ldrht
arm_inst_strht
这两个和前面的 ldrh_i / strh_i / ldrh_r / strh_r 不同点是：
1. 它们没有 P/W 字段参与寻址。
2. REGFORM1 bit[22] 控制寄存器形式或立即数形式。
3. 内存访问地址始终是原始 Rn 地址。
4. offset_addr 只用于写回 Rn。
5. 内存访问最后一个参数是 TRUE，也就是 unprivileged 访问。
 
⸻
 
一、字段规则
这两个函数用到的字段是：
cond      bits[31:28]
U         bit[23]
REGFORM1  bit[22]
Rn        bits[19:16]
Rt        bits[15:12]
imm4H     bits[11:8]
imm4L     bits[3:0]
Rm        bits[3:0]
关键规则：
regform = ARM_INST_BITS(inst, ARM_INST_LDRSTR_REGFORM1_END,
                        ARM_INST_LDRSTR_REGFORM1_START) ? FALSE : TRUE;
所以：
REGFORM1 = 0 -> regform = TRUE，使用 Rm 作为 offset
REGFORM1 = 1 -> regform = FALSE，使用 imm4H/imm4L 作为 offset
 
⸻
 
二、公共模板
每条用例的 Value User Code 先写：
static struct vmm_vcpu vcpu;
static arch_regs_t regs;
unsigned int inst;

memset(&vcpu, 0, sizeof(vcpu));
memset(&regs, 0, sizeof(regs));

vcpu.is_normal = 1U;
regs.pc = 0x1000U;
regs.pstate = 0U;

inst = 0U;
然后追加每条用例自己的构造代码。
 
⸻
 
三、
arm_inst_ldrht
arm_inst_ldrht.001.R
构造代码
/* cond = AL */
inst |= (0xEU << ARM_INST_COND_SHIFT);

/* U=1, REGFORM1=0 -> regform = TRUE */
inst |= (1U << ARM_INST_LDRSTR_U_START);

/* Rn=1, Rt=2, Rm=3 */
inst |= (1U << ARM_INST_LDRSTR_RN_START);
inst |= (2U << ARM_INST_LDRSTR_RT_START);
inst |= (3U << ARM_INST_LDRSTR_RM_START);

vcast_reg_read_value[1] = 0x2000U;  /* Rn base */
vcast_reg_read_value[3] = 0x10U;    /* Rm offset */

vcast_mem_read_value_seq[0] = 0x1234U;
vcast_mem_read_rc_seq[0] = 0;

<<emulate_arm.arm_inst_ldrht.inst>> = inst;
<<emulate_arm.arm_inst_ldrht.regs>> = &regs;
<<emulate_arm.arm_inst_ldrht.vcpu>> = &vcpu;
期望值
return = 0

regs.pc = 0x1004

vcast_mem_read_call = 1
vcast_mem_read_addr_seq[0] = 0x2000
vcast_mem_read_size_seq[0] = 2

vcast_reg_write_called[1] = 1
vcast_reg_write_value[1] = 0x2010

vcast_reg_write_called[2] = 1
vcast_reg_write_value[2] = 0x1234
说明：
offset = Rm = 0x10
address = Rn = 0x2000
offset_addr = address + offset = 0x2010
mem_read 使用 address，也就是 0x2000
Rn 写回 offset_addr，也就是 0x2010
注释
测试目的：验证 ldrht 在寄存器偏移形式、U 位为 1 时，能够从原始 Rn 地址读取半字，并将 Rn 写回为 Rn 加 Rm 偏移后的地址。 用例类别：基于需求的测试 预置条件：构造有效 VCPU 和寄存器对象；设置 Rn 读返回 0x2000；设置 Rm 读返回 0x10；设置内存读取返回 0x1234。 测试步骤： step1、构造 inst，设置条件码为 AL。 step2、设置 REGFORM1=0，使指令进入寄存器偏移形式。 step3、设置 U=1、Rn=1、Rt=2、Rm=3。 step4、设置 R1 返回 0x2000，R3 返回 0x10。 step5、设置 cpu_vcpu_mem_read 第一次读取返回 0x1234。 step6、调用 arm_inst_ldrht。 step7、观察返回值、PC、内存读取地址、Rn 写回值和 Rt 写入值。 用例来源：需求分析、有效等价类 追溯ID：arm_inst_ldrht 等价列表：寄存器偏移形式、U=1、条件成立、内存读取成功。 其它说明：本用例覆盖 regform=true、add=true、条件成立、内存读取成功路径。 通过准则：函数返回 0；PC 更新为 0x1004；内存读取地址为 0x2000；R1 写回 0x2010；R2 写入 0x1234。
