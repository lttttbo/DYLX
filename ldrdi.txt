下面给下一组：doubleword immediate load/store 两个接口：
arm_inst_ldrd_i
arm_inst_strd_i
这组比半字类多了两个关键点：
1. Rt 必须是偶数。
2. 会连续访问两次内存：
   ldrd_i：读 address 和 address + 4，分别写 Rt 和 Rt+1。
   strd_i：读 Rt 和 Rt+1，分别写 address 和 address + 4。
字段使用：
cond   bits[31:28]
P      bit[24]
U      bit[23]
W      bit[21]
Rn     bits[19:16]
Rt     bits[15:12]
imm4H  bits[11:8]
imm4L  bits[3:0]
每条用例先使用公共模板：
static struct vmm_vcpu vcpu;
static arch_regs_t regs;
unsigned int inst;

memset(&vcpu, 0, sizeof(vcpu));
memset(&regs, 0, sizeof(regs));

vcpu.is_normal = 1U;
regs.pc = 0x1000U;
regs.pstate = 0U;

inst = 0U;
