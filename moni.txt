以下表格按32 个物理 CPU、每个物理 CPU 固定绑定 2 个同优先级 vCPU的模拟测试场景编制。P1、P2 测试期间 vCPU 不迁移、不阻塞，P3 使用单独的周期唤醒测试。
以下补充实测值为模拟数据，用于展示形式化性质验证过程。
1. 验证参数
参数	取值	说明
物理 CPU 数量	32	每个物理 CPU 独立调度
每核测试 vCPU 数 N	2	同优先级轮转
测试 vCPU 总数	64	32 × 2
配置时间片 Q_{cfg}	10 ms	Hypervisor 默认时间片
中断延时最大值 A→B	2.980 μs	25 小时测试结果
vCPU 切换最大值 B→C	1.120 μs	25 小时测试结果
Timer 最大迟到	0.620 μs	模拟补充数据
安全余量	0.280 μs	工程余量
净执行时间片 Q	9.998880 ms	10ms-1.120μs
系统开销上界 \Delta Sys	5.000 μs	2.980+1.120+0.620+0.280
测试时长	25 h	90,000 s
调度轮长为：
roundLen=N(Q+\Delta Sys)
roundLen=2\times(9.998880+0.005) =20.007760\ ms
 
⸻
 
2. P1 CPU 带宽性质验证
P1 性质：
cpuTime[v]\times roundLen \geq (globalClock-2\times roundLen)\times Q
理论 CPU 带宽下界：
B_{min}=\frac{Q}{N(Q+\Delta Sys)} =49.9750\%
验证项	理论下界	模拟实测最差值	安全余量	结果
25 小时 CPU 执行时间	44,977.489 s	44,990.820 s	13.331 s	PASS
CPU 带宽	49.9750%	49.9898%	0.0148 个百分点	PASS
 
⸻
 
3. P2 最大服务间隔性质验证
P2 性质：
maxGap[v]\leq P2\_LWorst
P2\_LWorst=(N-1)(Q+\Delta Sys)+\Delta Sys
代入参数：
P2\_LWorst =(2-1)\times(9.998880+0.005)+0.005 =10.008880\ ms
验证项	理论上界	模拟实测最大值	安全余量	结果
vCPU 最大服务间隔	10.008880 ms	10.006420 ms	2.460 μs	PASS
 
⸻
 
4. P3 最大唤醒延迟性质验证
P3 性质：
maxWakeupDelay[v]\leq P3\_WWorst
P3\_WWorst=N(Q+\Delta Sys)
代入参数：
P3\_WWorst =2\times(9.998880+0.005) =20.007760\ ms
验证项	理论上界	模拟实测最大值	安全余量	结果
vCPU 最大唤醒延迟	20.007760 ms	20.004260 ms	3.500 μs	PASS
 
⸻
 
5. P2、P3 一致性验证
模型要求：
P3\_WWorst=P2\_LWorst+Q
验证项	左侧计算值	右侧计算值	结果
P3\_WWorst=P2\_LWorst+Q	20.007760 ms	10.008880 + 9.998880 = 20.007760 ms	PASS
 
⸻
